# Goji Perspectivism

A small multilingual learning space for comparing ideas and everyday expressions across Nigerian Hausa, Yoruba, Igbo, and Nigerian Pidgin.

## What is perspectivism?

Perspectivism treats language as a way of seeing and interpreting the world. This project presents parallel expressions with English glosses so learners can compare wording, tone, and cultural context without treating any language as a mere translation of another.

## Supported languages

- Hausa
- Yoruba
- Igbo
- Nigerian Pidgin

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

The example entries in `src/data/phrases.ts` are starter content for the interface and should be reviewed by fluent speakers before being treated as authoritative language documentation.
